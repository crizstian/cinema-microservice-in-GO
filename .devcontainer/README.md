# Development Container Configuration

Esta carpeta contiene la configuración mínima para VS Code Dev Containers.

## 📁 Ubicación Real

Los archivos Docker del devcontainer están centralizados en:
```
platform/docker/devcontainer/
├── Dockerfile
├── docker-compose.yml
├── devcontainer.json
└── README.md (documentación completa)
```

## 🚀 Uso

Para usar el devcontainer:

1. Abre el proyecto en VS Code
2. Presiona `F1` → `Dev Containers: Reopen in Container`
3. Espera a que se construya (~3-5 min primera vez)
4. ¡Listo!

## 📚 Documentación

Ver documentación completa en: `platform/docker/devcontainer/README.md`

---

**Nota**: Este archivo solo configura VS Code para encontrar el devcontainer en su nueva ubicación centralizada.
